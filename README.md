# 运维 / SRE 岗位手册

> 一份面向 **运维 / SRE 岗位**的学习知识库，覆盖从单机 Linux 到容器编排、再到 GPU/RDMA 基础设施的完整链路。
>
> **定位**：不是把命令再过一遍，而是把「生产中真正会遇到的问题」和「面试官真正会追问的点」对齐——每个主题都按 **概念 → 生产实践 → 要点自测** 三层推进，验收标准从「能讲清」提升到「能交出东西」（一份基线卡、一份带回滚的变更记录、一段 Runbook）。
>
> **读者定位**：会基本 Shell、用过 `top`/`systemctl`/`kubectl`，但缺乏「从现象到根因」系统方法论、需要一套可复现、可交叉引用的复习地图的运维 / SRE 新人。

## 快速开始

1. **在 GitHub 上直接读**：所有目录与入口链接都是标准 Markdown 相对链接，点开即可浏览。
2. **在 Obsidian 中读（推荐）**：用 Obsidian 把本目录作为库打开，可获得篇内 wikilink、Mermaid、callout 的完整渲染与跳转（各篇笔记使用这些语法，GitHub 页面上不会渲染）。
3. 新人或按模块复习：从 [Linux 学习大纲](Linux/00_学习大纲.md) 进入，按「学习路径总览」逐阶段推进，每章入口是 `NN_主题/00_导读与知识地图.md`。
4. 容器与编排方向：[Kubernetes 学习大纲](Kubernetes/00_简介.md)；GPU/RDMA 数据面方向：[AI-Infra 学习大纲](AI-Infra/00_简介.md)。
5. 跨主题复习：三份大纲各有一张「边界表」（见下），先厘清某个知识点属于哪份大纲，再回对应篇目深挖。

## 三大主题域的边界

同一个知识点只在一份大纲里展开，其余只引用不重复：

| 内容 | 归属 | 说明 |
| --- | --- | --- |
| 通用主机能力：systemd、内存/OOM、文件系统、TCP 排障、权限安全、日志监控、性能方法论 | [Linux 大纲](Linux/00_学习大纲.md) | 基础层，其余两份大纲的前置 |
| 通用主机侧调优：IRQ 亲和、软中断、MTU、网卡环形缓冲 | Linux 大纲 阶段 6 / 10 | 不放进 AI-Infra |
| 容器编排：K8s 对象、控制器、调度/QoS、CNI/CSI、安全、GPU 编排与 gang 调度 | [Kubernetes 大纲](Kubernetes/00_简介.md) | 编排与控制面 |
| GPU/RDMA 数据面：驱动与内核模块、PCIe/NUMA、RoCE/IB 无损网络、perftest、XID 硬件故障 | [AI-Infra 大纲](AI-Infra/00_简介.md) | 主机与网络数据面 |
| 训练 I/O 数据面：checkpoint、数据加载、共享文件系统、GPUDirect Storage | AI-Infra 大纲 阶段 7 | 通用文件系统知识仍见 Linux 大纲 |

**衔接关系**：Linux 是 Kubernetes 的前置（`namespace`/`cgroup`/网络排障在 `Kubernetes/03_调度_资源_QoS` 与 `04_网络` 直接复用）；AI-Infra 依赖 Linux 主机能力、并与 `Kubernetes/08_GPU_AI场景` 以「主机数据面 vs 编排控制面」为界；主机侧排障动作在三套体系下完全通用。
