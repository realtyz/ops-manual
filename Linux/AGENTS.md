# Repository Guidelines

本仓库是 Obsidian 中的 Linux 运维学习笔记库，不是代码工程：没有构建系统、依赖管理与自动化测试。贡献即「写作」，优先保证**准确、可复现、可判断**。

**内容怎么写，一律以 `Linux/写作规约.md` 为准**；本文件只讲仓库结构、协作流程与校验方式。

## 结构

- `00_学习大纲.md`：学习路线图，各阶段按**里程碑**过关（不设天数）。
- `写作规约.md`：内容写作的唯一依据。
- `AGENTS.md`：本文件。
- `NN_主题/`：每个阶段一个目录，内含：
  - `00_导读与知识地图.md`：**导航篇**，只承担地图职责——知识地图（时间主线 + 横切线）、术语速查、故障现场定位表、篇目索引、参考文档；
  - 其余为**正文篇**，前缀即分层：`原理_` / `体系_` / `实操_` / `判例_` / `治理_`。
- 命名形如 `NN_层_关键词.md`；叙事不写进文件名。
- 模板已废弃：新篇直接按规约第三节的骨架写。
- 图片与附件与所在笔记同目录，文件名避免空格与特殊字符。

## 写作：以 `写作规约.md` 为准

最容易忘的三条（完整清单见规约第四节）：

1. **不写结构声明**：不写"这篇讲什么""必须先读什么""和后面的关系"。
2. **不出现等级与技能编号**（`M1–M8`/`T0–T4`/`L1–L4`），原理篇不写动手章节与脚本。
3. **给出数值就要给出读法**：是什么、单位、判据、与谁同看、转向哪一步——五件事缺一不可。

## 以文档为准，实机其次

机制、默认值、字段口径**先查权威文档**（man、内核 `Documentation/`、发行版官方文档、厂商手册）；文档说不清或与观察冲突时才上机，并且：

- 上机结果与内核版本、发行版、硬件、容器环境强相关，**没出现预想结果优先怀疑环境不匹配**；
- 内核文档与 man 手册按**与目标机器同一主版本**取（优先 6.x），引用时写明依据的版本；老版本 `Documentation/` 里的接口与默认值可能已经变过；
- 要把实机结果写进正文，必须写清环境，并说明它可能只在该环境成立；
- 客观事实（关键路径、字段名、输出格式、版本门控）可以也应当上机核对。

**金标准环境**（需要复现时的默认机器，不是结论的适用范围）：Ubuntu 24.04.5 LTS（VMware 虚拟机）/ 内核 `6.8.0-139-generic` / systemd 255（`255.4-1ubuntu8.17`）/ cgroup v2 / 4 vCPU / `MemTotal` 约 7894 MiB / swap 4095 MiB / 根分区 ext4 on LVM / 时区 `Etc/UTC` / root 可用，另有 `realtyz`（uid=1000）。实验机 `192.168.246.128`（root 与 realtyz 均免密）。已知限制：该机 `perf` 的 `dTLB-*` 事件恒为 0，`numactl --hardware` 只有 1 个节点——涉及 TLB 计数与 NUMA 的结论不可在该机取得。

## 校验

定稿前逐条走完规约第九节的自检。仓库级的三条人工校验：

1. **计数一致性**：本文件阶段表、`00_学习大纲.md` 的阶段描述、各章 `00_导读` 的篇目索引，三者与实际目录一致（`Get-ChildItem <章目录> -File`）；
2. **链接解析**：导航篇里的 wikilink 逐个确认存在；正文篇不应有 wikilink；
3. **编码纪律**：这些笔记是 UTF-8 中文，用脚本读时必须显式指定 UTF-8（PowerShell 用 `-Encoding UTF8`）；按默认编码读会把中文变成 `?`，让 `(?m)^created:` 这类行首正则失配并产生假告警。

## Commit 与 PR

本目录由上级仓库 `ObsidianNote` 管理（Git 根在上一级）。提交信息写成 `docs: 重写阶段 4 为原理＋体系结构`、`fix: 修正 free used 口径等 3 处事实错误` 这类，说明改了哪篇与为什么。PR 需包含：受影响笔记清单、验证环境（发行版/内核/是否上机核对）、阶段表与大纲是否同步更新、涉及 Mermaid 时的渲染截图。

## Agent 专用指令

- 动手前先读 `写作规约.md` 与目标章的 `00_导读`；**阶段 4 是"写到什么程度算完"的参照**。
- **只改正在处理的那一章**，不顺带改动其他章节；跨章同步按上面「必须同步三处」执行。
- 机制与默认值先查文档；必须上机时遵守「以文档为准」一节的纪律，并标注环境。
- 写完一篇后立即做规约第九节的自检，不要攒到最后。
