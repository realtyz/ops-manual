# 第 09 章 GPU 的数据从哪里来：存储与 I/O｜内容大纲

## 读者起点与学习目标

本章位于多机协同与数据供给阶段的末尾。第 01、02、04 章已经建立主机内存、显存、页锁定缓冲、H2D DMA、PCIe/NUMA 和 CUDA Stream 的基本关系，第 05、08 章已经解释 Rank、同步步、集合操作及慢成员怎样传播等待，第 06 章的 GPUDirect RDMA 为区分“网卡访问显存”和“存储访问显存”提供对照。本章在这些认识上补齐存储、数据加载与保存恢复，不重复展开设备拓扑或集合算法。

读者具有 Linux 与 Kubernetes 基础，无需 GPU、CUDA 编程或分布式训练实验经验。读完应能：

1. 沿一批训练样本说明索引、文件读取、页缓存、CPU 解码、批整理、主机缓冲、H2D 与计算之间的依赖，并按样本速率分别计算存储载荷和设备输入量。
2. 根据文件布局、请求大小、请求率、并发和缓存状态，区分元数据、随机小读、顺序吞吐和共享路径约束；说明本地 NVMe、NFS、Lustre 与对象存储各自改变了哪段路径。
3. 从阶段速率与依赖推导串行和流水线的出批间隔，判断 worker、预取、页锁定和异步 H2D 能解决什么、不能解决什么，并估算在途批次的主机内存代价。
4. 跟踪 Checkpoint 从一致状态到发布版本、再到恢复就绪的过程，用完成窗口、保留策略和并发恢复估算带宽、容量与读取下界。
5. 对比普通主机中转与 GPUDirect Storage（GDS）直达路径，按文件、缓冲、设备和软件栈判断候选路径，并选择证据核实实际路径。
6. 对齐多 Rank 的取批、H2D、Kernel、集合和 Checkpoint 记录，找出最早晚到的阶段，设计一次只移除一段路径的对照，避免把通信等待直接等同于网络故障。

## 贯穿案例与技术口径

- 主例使用节点 `gpu-a`、`gpu-b`，Rank 0/1 在 A，Rank 2/3 在 B，每 Rank 一个训练进程和一张 GPU。每 Rank 每步 32 个图像样本，目标步时 125 ms；存储中的编码样本平均 256 KiB，整理后的输入张量为 1 MiB。假定 Rank 分片互不重叠、每样本读一次；若采样器 padding 造成重复索引，则另行重算。全作业需要 1,024 样本/s、256 MiB/s 冷读有效载荷和 1 GiB/s H2D 输入量；每节点分别为 512 样本/s、128 MiB/s 和 512 MiB/s。协议、预读放大、索引和重试只有进入特定算例时才加入。
- 本章只沿用第 08 章的两节点四 Rank 形状，不继承其单数据端口或第 01 章的存储专网接线。存储读、Checkpoint 写与集合流量是否共用物理资源，必须在相应算例中说明；未给出端口和拓扑材料时，不作物理争用或分用结论。
- 数据加载以 [PyTorch 2.9 DataLoader](https://docs.pytorch.org/docs/2.9/data.html) 和对应 `v2.9.0` 源码为行为锚点；CUDA 的 Stream、页锁定和重叠引用与正文一致的归档版本。存储接口分别使用 Linux/NFS、Lustre 和 Amazon S3 官方资料。它们是不同的访问路径实例，不把产品示例写成通用性能排名。
- Checkpoint 以 PyTorch 2.9 Distributed Checkpoint（DCP）的文件写入实现为例，区分应用契约、框架完成和具体后端的持久性。GDS 主例保留 CUDA 12.9 系列、GDS 1.14、Linux x86_64、单 NVMe/XFS 的版本条件；配置、工具和统计字段在目标版本上仍需复核。
- 所有速率、时间线和应用字段均为可复算的教学设定，不声称已在实机执行。性能模型区分有效载荷、链路流量、规格峰值与实测；命令和配置用于说明观察目的。第 17—19 章再组织常态监控、跨层故障处置和集群验收，本章只建立局部证据的含义。

## 范围与材料处理

本章不展开存储系统安装、RAID/条带调优、对象存储服务管理、完整训练算法或模型算法，也不把 GDS 当作所有数据加载的默认替代方案。容器挂载交给第 10—13 章，作业重启与调度交给第 15—16 章。推理模型冷启动只在恢复语义处对照。

保留原稿的一批次路径图、供给速率表、小文件/分片算例、三级预取与内存预算、DCP 时序、Checkpoint 容量/带宽算例、GDS 三路图和多 Rank 对照实验。修正原流水线例子中“单 worker 生产需 140 ms，却直接得到 125 ms 稳态间隔”的条件跳跃；补齐双 worker 与资源独立的假设。原第 02、03 篇互换位置并重新命名，其余篇名按实际内容明确化，图号 `09-05-01` 和 `images/` 相对路径保持不变。新增第 99 篇承担整章综合检验。
