# 从普通网络通信走向 RDMA

两个进程要把一块数据交给对方，网卡怎样找到缓冲区？应用提交请求后，什么时候可以改写原缓冲？如果数据原本在显存里，主机内存还要不要接住它？本章沿这些问题，从熟悉的 Socket 进入 RDMA，再走到 GPU 与网卡的直接访问。

本章的学习任务是：**画出 Socket、主机内存 RDMA 与 GPUDirect RDMA 的有效负载路径；用 QP、CQ、MR、PD 解释一次传输的准备、提交和完成；判断访问权限、缓冲生命周期及 GPU—NIC 支持证据。** 学完后，应能从一组材料说清传输停在哪一环，并在条件充分时给出地址、事件或耗时推导。

## 前置与章节边界

已有 Linux 进程、虚拟内存、系统调用与 Kubernetes 基础即可。[第 03 章](../03_从驱动到CUDA应用的软件依赖/00_导读.md)提供用户态库、内核模块和设备访问的分工；[第 04 章](../04_单机多卡与GPU数据路径/00_导读.md)提供 PCIe、NUMA、DMA 与异步完成。这里会重新解释当前推导所需的最小含义，不要求读者编写网络或 CUDA 程序。

第 05 章主责多卡作业的成员与集合通信。本章只需其中的一个动机：作业有多个协作进程，进程产生的数据要交给其他成员，接收完成后才能推进依赖它的工作。一个进程可以称为一个 Rank；本章只研究 A、B 两个进程的一次数据交付，不要求先掌握某种并行算法。

本章完整解释主机侧硬件 RDMA 快路径、Verbs 对象、RC 连接、Send/Receive 与 Read/Write、完成语义、驱动栈及 GPU 内存注册条件。首次出现的 RDMA 专有概念均在本章建立。第 07 章负责 InfiniBand、RoCEv2 寻址、网络拓扑与拥塞控制；本章将网络视为已选好路径的传输段，只解释它与端点建链的接口。第 08 章负责 NCCL 组织与选择路径；第 10、13 章负责容器和 Pod 的设备接入；第 17—19 章负责系统基线、排障处置与变更。本文不展开交换机配置、容器安装或性能调优参数大全。

## 贯穿材料的约定

本章新建一套最小双节点模型，**不沿用前章四卡节点的编号、地址、能力表或 25 GB/s 预算**。节点 `rdma-a`、`rdma-b` 各运行一个宿主机进程 A、B，各有一个 RDMA 网卡端口（分别称 NIC-A、NIC-B）、一张数据中心 NVIDIA GPU。前四篇只使用主机 DRAM，第五篇才加入显存。A 与 B 的设备名即使相同，也属于不同主机。

| 项目 | rdma-a | rdma-b |
| --- | --- | --- |
| 主机内存缓冲代号 | H-A | H-B |
| RDMA 设备 / 端口 | `mlx5_0` / 1 | `mlx5_0` / 1 |
| 对应以太网接口 | `ens6f0np0` | `ens6f0np0` |
| NIC PCI BDF | `0000:43:00.0` | `0000:43:00.0` |
| GPU 代号 / PCI BDF | G-A / `0000:41:00.0` | G-B / `0000:41:00.0` |
| 本地 QP 号（教学十六进制） | `0x101` | `0x202` |

数据端口采用 RoCEv2，模型已给定网络可达、地址和路径参数匹配。RoCEv2 是在以太网/IP 网络上承载 RDMA 的方式，不走普通应用 TCP 数据流；本章使用的 **RC（Reliable Connection，可靠连接）**是 QP 的传输服务类型，并不是“TCP 连接”的别名。基础操作的解释不依赖某套 RoCE 拥塞配置。

所有图、地址、日志式记录与时间均为**自拟教学材料**，使用处注明人工整理或删节；没有 RDMA/GPU 实测。主机示例限定普通、预先注册的缓冲，不用 ODP（按需分页）、Inline、共享接收队列或 Relaxed Ordering。每个 SQ 请求都要求报告完成，错误记录彼此独立。缓冲地址采用半开区间；`KiB = 1024 B`，`MiB = 2^20 B`，带宽使用十进制 `GB/s`，链路速率使用 `Gb/s`。小消息例题用于说明机制，吞吐题另给独立的大缓冲与稳定速率条件。

Verbs 语义固定参考 **rdma-core v56.0** 上游手册；GPU 路径参考 **CUDA 12.8.1**，DMA-BUF/Peer Memory 条件对照 **GPU Operator 25.3.0** 的先决条件表，借用该表只为辨认宿主机依赖。Linux 与厂商驱动关系另核对 DOCA 3.4.0/3.5.0 归档资料。它们是阅读基线，未构成经过测试的整套部署版本组合。资料核对日期：**2026-11-08**。
