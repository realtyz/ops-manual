# 存储与 I/O 数据面

## 知识地图

### 一次训练迭代里的两条 I/O 路径：五段

本章的主链是**一次训练迭代的时间线**。它从读取一批样本开始，经过计算、梯度归约，最后在若干轮之后把参数写到存储；两条 I/O 路径的特征完全不同，因此瓶颈的表现形式也不同。

| 段 | 这一段在做什么 | 到这里要能说清 |
| --- | --- | --- |
| 1 读取样本 | 数据加载进程从存储读取样本、做预处理并放入队列 | 这条路径的特征（持续、并发高、常伴大量小文件）与瓶颈落点 |
| 2 计算与归约 | 数据被送入计算设备，随后做梯度归约 | 这一段不属本章，但要能把它与等待数据区分开 |
| 3 周期性写出 | 每隔若干轮把所有进程的参数写到存储 | 这条路径的特征（突发、大块顺序写、全进程同时发起）与瓶颈落点 |
| 4 观测与归因 | 用主机侧与设备侧的读数判断此刻卡在哪一条路径上 | 哪几项读数组合起来能证明「设备在等数据」 |
| 5 缓解与取舍 | 按根因选择分片写、错峰、本地缓存或管线调整 | 每种缓解手段各自的空间代价与可靠性代价 |

**贯穿本章的三问**：这次慢是**等数据**还是**算得慢**；瓶颈落在带宽还是元数据；这条路径与另一条路径是否共享同一套存储后端。

### 两个跨阶段的核对对象

| 核对对象 | 它贯穿哪几段 | 每一处读什么字段 |
| --- | --- | --- |
| 设备侧的等待信号 | 它贯穿段 1、段 3 与段 4，因为设备利用率的变化形态是区分两条路径最快的证据 | 在段 1 读设备利用率的形态（持续偏低还是周期性归零）与数据加载进程的等待状态；在段 3 读同一组读数在写出窗口内的表现；在段 4 把设备侧形态与主机侧存储读数放在同一时间轴上对照 |
| 存储后端的容量与吞吐 | 它贯穿段 1、段 3 与段 5，因为容量、带宽与元数据操作数是三个不同的量 | 在段 1 读单次读取的延时与元数据操作数；在段 3 读写入窗口内的吞吐与队列深度；在段 5 核对两条路径是否落在同一后端，以及各自占用多少余量 |

## 术语速查

| 名词 | 一句话解释 | 在哪一篇展开 |
| --- | --- | --- |
| checkpoint 写 | 周期性把所有进程的参数落盘的动作，特征是突发、大块顺序写 | 原理：两条 I/O 路径的特征差异 |
| 数据加载 | 持续把样本读入并预处理后送入计算设备的过程 | 原理：两条 I/O 路径的特征差异 |
| 元数据子系统 | 并行文件系统里负责目录与文件属性操作的部件，海量小文件读的瓶颈常在这里 | 原理：海量小文件为什么是并行文件系统的死角 |
| 分片并行写 | 把一次检查点写成多个分片、由各进程分别写出的做法 | 原理：两条 I/O 路径的特征差异 |
| 错峰 | 让不同进程或不同作业在不同的时间点写出，避免同一时刻打满存储 | 治理：存储基线与作业级 I/O 指标 |
| GPUDirect Storage | 让存储设备直接读写显存、绕过主机内存中转的路径 | 原理：存储到显存的直通路径省掉了哪一段 |
| `cuFile` | 实现存储到显存直通读写的用户态接口 | 原理：存储到显存的直通路径省掉了哪一段 |
| 存储基线 | 与网络基线同性质的一组正常值，包含顺序读写、随机读写与元数据操作数 | 实操：I/O 观测与存储基线 |
| 加载管线 | 从读取到送入设备之间的全部环节，包含预处理与缓存 | 原理：两条 I/O 路径的特征差异 |

## 关键字段的读法

| 字段 | 是什么与单位 | 判据 | 与谁同看 | 转向哪一步 |
| --- | --- | --- | --- | --- |
| 设备利用率的时间形态 | 单位时间内设备处于工作状态的比例，通常按秒采样 | 持续偏低说明管线供不上；周期性归零且周期与检查点间隔一致说明卡在写出 | 与数据加载进程的等待状态同看 | 出现周期性归零时，转入写出路径的排查 |
| 磁盘读写的 `await` | 单个请求的平均耗时，含排队时间，单位是毫秒 | 它高不等于盘慢，必须与队列深度、请求规模一起读 | 与同一次采样里的队列深度与吞吐同看 | 若队列深度很高而 `await` 也高，说明在排队；若队列深度很低而 `await` 高，转入介质与后端排查 |
| 元数据操作速率 | 单位时间内完成的目录与属性操作数 | 海量小文件场景下它先于带宽饱和 | 与单次读取的延时同看 | 若带宽未满而延时上升，转入元数据子系统的排查 |
| 写入窗口内的吞吐 | 单位时间内写入的数据量 | 与存储后端的可用带宽对照；同步写入时所有进程会同时竞争 | 与队列深度同看 | 若写入期间计算设备空闲，转入分片写、错峰与本地缓存的取舍 |
| 直通读写的生效状态 | 存储到显存的直通路径是否真的启用 | 启用与否的差别要用同一数据集、同一参数的对照测量来证明 | 与主机内存占用与处理器占用同看 | 若对照无差异，先确认文件系统与内核模块是否满足前提 |
