# 第 12 章审查与验证记录

本记录对应导读、六篇正文、十组题目与参考分析，以及八幅待生成配图的完整交付。记录的是文稿、技术资料和结构检查，不是 GPU 集群实验报告。

## 学习任务与写作边界

写作前确定学习路径为：**软件依赖与责任 → 配置和调谐 → 新节点变化 → 分层证据 → 供给与异构约束 → 综合推演**。学习成果是能画出依赖、指定维护者、关联目标与实际状态、判断未完成环节，并评审一份组件交付材料。

读者已有 Linux/Kubernetes 基础；直接前置为第 03 章驱动、第 10 章容器接入和第 11 章设备资源管理。新建立 Operator、受管理组件、ClusterPolicy、调谐与 Validator 的最小概念集。设备分配机制不重复展开；网络接入留在第 13 章，共享切分留在第 14 章，指标解释留在第 17 章，生产变更流程留在第 19 章。异构驱动 API 只讲理解差异所需的边界。

本章使用独立 op-a/op-b 两节点、每节点两张 L4 模型，固定 GPU Operator v25.3.0 与传统插件/legacy 交付；不承接第 11 章的 DRA 场景，也不把 Toolkit 1.18 的默认机制套给本章 1.17.5。

## 实际验证范围

- **内容审查**：通读导读、六篇正文、十组答案与八份提示词，逐项对应大纲任务并沿依赖复查受影响位置；核对版本、组件数量、等待信号、管理责任、Node 数量与单卡验证的边界。

- **计算复核**：程序复算向量结果及第 03 篇、练习第 5 题的节点数量余额，核对单 Pod 不能跨节点合并请求。
- **结构复核**：检查本章 **9 个 Markdown 文件、40 个本地链接、26 个不同外部来源 URL、5 段 YAML 与 9 份 frontmatter、2 段 Mermaid、8 个配图定位与完整提示词、10 对题目与参考答案**，并检查大纲与第 11 章末新增导航。YAML 可解析，配图定位原句在所属正文唯一匹配；26 个来源均可访问，GitHub 文件通过固定 tag 的 raw 路径核验。Mermaid 核对节点/边关系、声明与结构，未进行实际渲染。最后一轮结构检查未报错。

这些检查不包含 Kubernetes API schema 校验、Helm 实际安装或调谐、内核模块构建、容器创建、CUDA 探针执行和 GPU/RDMA 实机测试。正文中虚构镜像没有制作或发布。未生成图片，没有图片视觉验收或嵌入；未检查 Obsidian 显示效果。
