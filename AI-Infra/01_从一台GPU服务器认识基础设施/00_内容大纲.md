# 第 01 章 从一台 GPU 服务器认识整套基础设施｜内容大纲

## 读者从哪里出发

读者会读 Linux 进程、主机内存、块设备、网口和路由信息，具备 Kubernetes 基础。以双路 x86 服务器和 NVIDIA 独立 GPU 为例，从一批输入到达 GPU 的过程建立硬件与拓扑基础。案例阅读只需本章给出的材料。

学完本章，读者应能完成三件事。

1. 画出本地盘或远端存储的数据如何进入目标 GPU，标明负责提交操作和搬运数据的组件，按目标设备的可用量判断一次显存分配。
2. 用设备树、线程位置和页驻留信息重建一条 PCIe/NUMA 路径，解释移动缓冲区或改变并发方向时，跨 Socket 路径和共享上行预算怎样变化。
3. 从规格表辨认 GPU、底板、整机和机架的边界，把管理、协调、GPU 通信与存储映射到端口和供电依赖，判断局部故障影响哪些环节及需要怎样的证据。

## 从一次输入走到集群

| 篇次与主题                     | 概念与推导安排                                                                                                                                                   |
| ------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 01 一份配置表里的设备各做什么          | 从一批待并行处理的输入引出独立 GPU、显存及其与主机的分工。沿本地 NVMe 缓存未命中、主机处理、显存复制和 GPU 执行走通主例，就地解释 PCIe、Switch 与 DMA。再换成远端输入，用 DGX H100 官方组件表复算八卡 640 GB，比较单卡分配与应用分片。               |
| 02 从设备清单画出 PCIe 和 NUMA 拓扑 | 把 01 的设备挂到教学节点的根端口和 Switch 上，再引入 Socket、PCI 功能地址和 NUMA 节点。先固定线程、桥路径和本地缓冲区，再只改变页落点，区分 DMA 读取请求与返回数据。用 Linux 字段还原三个位置，最后以 12 + 12 对 16 GB/s 检查同方向的共享上行。     |
| 03 从 GPU 形态读到整机平台         | 有了主机侧连线，再分别读取安装形态、主机 PCIe 和 GPU 互联。保留 H100 SXM 与 PCIe 的规格对照，区分 H100 NVL。由 HGX 底板补齐整机边界，用 8U DGX H100 与 6U XE9680 对照说明更换机型后需要重查哪些规格。                       |
| 04 带内外管理与运行条件             | 从管理者到 Linux、到 BMC 各走通一次访问，再用 Redfish 区分当前状态和历史事件。沿 PDU 到 PSU 再到整机输入，比较单模块故障与整路失电。保留 21.4 kW 的预算示范，结合机箱、气流和冷却条件理解交付范围。                                     |
| 05 把一台服务器的端口接到集群          | 在 A、B 双节点案例中先明确通信双方和用途，再由 PyTorch 2.8 协调端点定位 IP 路径，由 VLAN 110/120 与线缆定位共有断点。以 trunk 或高速链路中断为变体，再以 BasePOD 的实际端口、bond 和独立计算网络对照。                           |
| 99 本章小节                   | 把数据、管理与供电路径放回同一张关系图。用 DGX H200 规格与明确给定的教学材料做一题综合交付评审，题干与参考推理依次呈现。读者需画路径、按设备核算显存、复算同向链路与 A/B 路预算，再预测页驻留、网卡接入、单路失电和存储端口变化的影响。新增双卡分片变式，检验能否在改变分配条件后重新判断单卡余量。 |

01 的简图只展示设备职责。02、05 和章末沿用教学节点的设备、桥与接口标识，05 的 A、B 在章末分别记为 N21、N22。DGX H100/H200、XE9680 与 BasePOD 提供产品规格或部署对照。H200 练习另给定共享上行、机架预算、显存和观测条件。

核心机制讲到能画出路径并推导变化。第 02 章再解释 GPU 内部执行与显存性能，第 03 章解释从设备枚举到应用可用，第 04 章解释多卡搬运、直连和实测。作业组建、设备直达、集群网络、通信库和数据供给依次在第 05—09 章深化。第 13、15、17—19 章复用端口映射、NUMA 对齐及运行证据。
