# 第 19 章 节点交付、版本变更与集群持续运行｜内容大纲

## 一、本章定位与前置知识

本章位于第四阶段“集群运维”的核心工程落地环节，承接 [第 10–13 章](../10_GPU如何进入容器/00_内容大纲.md) 的容器设备注入与高速网络接入、[第 14–16 章](../14_GPU共享、切分与隔离/00_内容大纲.md) 的推理切分隔离与成组调度，以及 [第 17 章](../17_把设备、网络与作业状态联系起来/00_内容大纲.md) 的性能基线和 [第 18 章](../18_从故障现象追到具体层次/00_内容大纲.md) 的分层排障方法。

第 18 章聚焦于故障发生后的单点诊断，本章则把工程防线前移到集群的全生命周期运维，回答五个实战问题：**一台新服务器凭什么进入生产资源池、多租户权限与高速网络如何防越权、双机架到底能承诺多少训推容量、版本升级如何在不中断推理 SLA 且可安全回滚的前提下排空试点、以及硬件故障后如何完成撤回与复归闭环**。

读完本章后，[第 20 章](../20_用完整场景串联整套知识/00_内容大纲.md) 将把整套交付、调度、排障与变更方法放进同一份跨生命周期的实战工单中综合演练。

## 二、核心学习目标

1. **建立配置基线与漂移治理意识**：区分配置基线、运行实态与性能基线，厘清节点镜像与 GPU Operator 的配置归属，沿“启动内核 → 驱动模块 → 用户态库 → 显存 RDMA”链条判定变更影响。
2. **闭环多租户权限与双网隔离边界**：沿 RBAC、Pod Security Admission、设备配额、`RuntimeClass` 准入、Multus NAD 引用及 RoCE 硬件转发执行点落实隔离，会用“同租户允许 + 跨租户拒绝 + 执行点计数”成对证据把关放行。
3. **落地训推双池分层验收标准**：掌握验收隔离污点与全机 8 卡 NVSwitch/Fabric Manager、GDR、集合通信及代表负载验收；能够明确区分**训练资源池**（全互联集合基线、并行存储吞吐）与**推理资源池**（MIG 隔离、本地盘权重预热、TTFT/TPOT SLO 基线）的差异化准入门槛。
4. **独立复算机架、网络、存储与维护余量**：从单路供电、持续散热、单向网络割面、存储错峰窗口与节点四维资源落点推导出集群可承诺的训推容量，在统一账本上核算计划维护余量与故障余量。
5. **掌控安全排空、金丝雀试点、恢复预算与节点复归**：独立推导检查点完整提交条件、关键路径 RTO 与 RPO 步数预算；区分训练作业（等检查点后整组退出）与在线推理服务（Readiness Probe + PDB + 优雅终止无损摘流）的排空流程，精准执行停批、回滚、坏卡撤回与维修复归验收。

## 四、本章贯穿场景说明

- **统一参考拓扑与软件栈**：沿用[全书基线与术语速查](../00_全书基线与术语速查.md)一致的**标准 8 卡 HGX H100（NVSwitch 全互联）双机架训推共存集群**。
  - 软件锚点为 Ubuntu 24.04 LTS、`6.8.0-52-generic`（基线 v1）/ `6.8.0-53-generic`（候选基线 v2）、开源模块 `595.91.07`、CUDA `13.2.1`、Kubernetes `v1.36`、containerd `2.3.0`、GPU Operator `v26.7.2` 与 Multus `v4.2.4`。
- **双机架双网络域布局**：域 A（机架 A，`node-1`–`node-4`）与域 B（机架 B，`node-5`–`node-8`，开篇时 `node-8` 待交付入池）合计 8 台 64 张 H100 80 GB。
  - 每台节点配 8 张 H100 SXM、`32` CPU、`192 GiB` 可调度内存、2 个共享 `200 Gb/s` RoCEv2 口的 SR-IOV VF，另配独立存储网与本地 NVMe 缓存盘（用于推理权重预热与 KV 卸载）。
- **训推双池共存口径**：支持整机交付，也支持本章主线的“**半机训练 + 半机推理**”共存模式——4 卡（含 1 个 VF）提供 1 个训练落点（同域 3 节点组成 `train-12`），另 4 卡（含 1 个 VF）承载 `infer-svc-1`（TP=2 或 MIG）。
  - 讨论不同硬件规格扩展时，会简明对照 4 卡直连 NVLink 机型的验收与供电差异。
- **既有手绘插画对照**：本章保留的 5 幅手绘插画中部分沿用了早期简标（`h1`–`h8` 对应 `node-1`–`node-8`，`B0`/`B1` 对应 `基线 v1`/`候选基线 v2`），正文原理段统一使用语义角色，在解读配图时自然完成映射。
