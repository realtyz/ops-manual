# 全书基线与术语速查

本文件是全书 20 章的**统一参考基准**。把示例口径、软件版本栈、参考拓扑和基础术语索引集中放在此处，目的是让各章正文甩掉重复的免责声明与反复重定义，专注把每一层的核心机制讲透。

## 一、全书示例、数据与单位口径

1. **示例与推演口径**：除明确标注来自厂商规格表或官方文档的硬件参数外，书中各章出现的节点名、地址、拓扑算例、命令输出、监控曲线与故障日志，均是围绕真实机制设计的说明性材料，用于在无 GPU 实机环境下帮助理解原理与推演过程。真实生产部署的配置默认值、兼容组合与性能表现，以目标环境的软硬件规格和实测为准。
2. **存储与内存单位**：
   - **二进制单位**（`KiB`、`MiB`、`GiB`、`TiB`，按 $1024$ 进制）：用于显存占用、主机内存容量、张量大小、KV Cache 体积、文件分片与检查点大小。
   - **十进制单位**（`KB`、`MB`、`GB`、`TB`，按 $1000$ 进制）：用于硬件标称规格（如 H100 80 GB 显存、NVMe 标称盘容）、HBM/PCIe 标称带宽（`GB/s`、`TB/s`）。
3. **网络带宽单位**：链路速率统一使用十进制比特每秒（`Gb/s`，如 `200 Gb/s`、`400 Gb/s`）；换算为理论最大字节吞吐（`GB/s`）时除以 $8$（例如 `200 Gb/s = 25 GB/s`），实际有效吞吐（Goodput）还需扣除协议开销与拥塞损耗。
4. **负载口径**：全书围绕**分布式训练**与**在线推理**两类核心 AI 负载展开。文中若不特别限定，训练默认以 Transformer 大模型同步训练为背景，推理默认以自回归大语言模型（LLM）在线服务为背景。

### 2. 命名与防撞名规范
- **讲解普遍原理时**：优先使用语义角色名，例如“发起节点 / 接收节点”“本地 GPU / 跨 CPU 远端 GPU”“主训练节点 / 慢节点 / 故障节点 / 备用节点”“在线推理实例 / 离线训练任务”。
- **必须出现实例标识时**：使用自解释的直观名称，禁止跨章撞名的双字符密码：
  - 节点：`node-1`、`node-2`（避免 `h1/h2` 与 `B0`、`N21` 混用）；
  - Pod / 作业：`train-worker-0`、`infer-svc-1`（避免 `P21`、`J17`、`J20`、`R1/R2`）；
  - 配置基线：`基线 v1` / `候选基线 v2`（避免 `B0/B1` 与数据块/主机名撞名）；
  - PCI BDF、UUID、网卡端口（如 `0000:65:00.0`、`ens6f0`、`swp12`）：集中放入映射表或带注释的命令/日志代码块中，不裸塞进大段原理散文。
